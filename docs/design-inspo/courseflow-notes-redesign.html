Same top bar, one added tab

Assignments/Notes reuses the exact segmented-tab component from the dashboard, so switching workspaces feels like part of the same app instead of a bolted-on screen.

Sidebar gets its own tint

A slightly warmer off-white (--sidebar) separates navigation from the editor/content pane without a hard border-heavy split.

3

Icons carry the teal accent

The flat black clipboard and gray feature icons are replaced with the accent-soft/accent-ink pairing used everywhere else — buttons, active rows, and badges.

4

Keyboard hints as chips

The plain gray key legend at the bottom becomes small bordered kbd chips, matching the chip language from the assignments toolbar instead of looking like debug UI.
