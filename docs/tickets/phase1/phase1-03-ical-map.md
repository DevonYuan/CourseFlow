## Description

Add a `mapICalToAssignments(events: ICalEvent[], sourceUrl: string): AssignmentInput[]` function in `src/backend/main/ical/` that transforms parsed `ICalEvent[]` into `AssignmentInput[]` ready for database insertion. Derive `courseId` from `CATEGORIES` or `SUMMARY`, `dueDate` from `DTSTART`, `source='ical'`, `sourceUrl` from `UID`/`URL`, `status='pending'`, `priority` from due date (sooner = higher).

---

## Requirements

### Functional

- [ ] `mapICalToAssignments(events: ICalEvent[], sourceUrl: string)` returns `AssignmentInput[]`
- [ ] **Course extraction heuristic** (in priority order):
  1. First `CATEGORIES` entry that looks like a course code (regex: `/^[A-Z]{2,4}\d{3,4}/`)
  2. Parse from `SUMMARY` prefix: `[COURSE] Title` or `COURSE: Title`
  3. Fallback: `"Unknown Course"`
- [ ] **Due date**: Use `dtstart` (Canvas uses `DTSTART` for due date)
- [ ] **Source tracking**: `source = 'ical'`, `sourceUrl = event.url ?? sourceUrl`, `icalUid = event.uid`
- [ ] **Status**: Default `'pending'` (other values: `'completed'`, `'archived'`)
- [ ] **Priority**: Numeric — sooner due date = higher priority (lower number = higher priority)
  - Calculate: `Math.floor((dueDate - now) / (1000 * 60 * 60 * 24))` → days until due
  - Clamp: 0 (overdue) to 999 (far future)
- [ ] **Title**: Use `event.summary` (trim whitespace)
- [ ] **Description**: Use `event.description` (may be HTML)
- [ ] **Course color**: Generate deterministic hex from course name (hash-based)
- [ ] Preserve `rrule` on Assignment for future expansion (Phase 2+)

### Non-Functional

- [ ] Pure function — no I/O, no side effects
- [ ] Zero `any` — `AssignmentInput` defined in `src/backend/shared/types.ts`
- [ ] Deterministic course color generation (same course = same color)
- [ ] Unit tests with varied `ICalEvent` inputs

### `AssignmentInput` Type (in `src/backend/shared/types.ts`)

```typescript
export interface AssignmentInput {
  id?: string; // UUID v4 (generated by repository if not provided)
  canvasId?: string; // Canvas assignment ID if available
  title: string;
  description?: string;
  courseName: string;
  courseColor: string; // Hex color #RRGGBB
  dueAt: number; // Unix ms (UTC)
  unlockAt?: number; // Unix ms (UTC)
  lockAt?: number; // Unix ms (UTC)
  pointsPossible?: number;
  submissionTypes?: string; // JSON string array
  workflowState?: string; // 'unsubmitted' | 'submitted' | 'graded' | ...
  htmlUrl?: string; // Canvas URL
  icalUid: string; // iCal UID for dedup
  source: 'ical' | 'manual'; // Source of assignment
  sourceUrl?: string; // Original iCal feed URL or Canvas URL
  status: 'pending' | 'completed' | 'archived';
  priority: number; // Lower = higher priority
  rrule?: string; // RRULE string for recurring events
  createdAt: number; // Unix ms (set by repository)
  updatedAt: number; // Unix ms (set by repository)
}
```

### Course Color Generation

```typescript
function generateCourseColor(courseName: string): string {
  let hash = 0;
  for (let i = 0; i < courseName.length; i++) {
    hash = courseName.charCodeAt(i) + ((hash << 5) - hash);
  }
  const hue = Math.abs(hash) % 360;
  return `hsl(${hue}, 65%, 45%)`; // Convert to hex if needed
}
```
